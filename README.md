# GN — George Naser Personal Website

Bilingual personal portfolio (English / German), built with HTML, CSS and vanilla JavaScript.

## Folder structure
Keep the following paths exactly as written (including capitalization):
- `index.html`
- `css/style.css`
- `js/site.js`
- `Assets/Images/`

The website expects these image files inside `Assets/Images/`:
- `GN_1.JPG` (hero portrait)
- `GN_2.JPG` (About portrait — this is the exact image used in the About section)
- `GN_4.JPG` (Oud Lab project image)
- `GN_5.JPG` (SOUL project image)
- `GN_5.JPG` (SOUL project image)
- `Logo1.png` (header logo; PNG is fully supported — use a transparent PNG with a light/gold mark for best contrast)

`GN_3.JPG`, `GN_5.JPG` and `Logo2.png` can remain in the folder for later use.

## Important before launch
1. The Connect section displays `george-naser@outlook.at` and links to the supplied Instagram profile.
2. Make sure your local image names and capitalization match exactly.
3. YouTube video thumbnails and playback require an internet connection.
4. Test the website locally in Chrome on desktop and mobile width.
5. GitHub Pages publishes a public website. Do not publish until you approve all visible content.

## GitHub Pages
For a GitHub Free personal account, the Pages source repository generally needs to be public. Keep the repository private during local design/testing, and make it public only when you are ready to launch.
